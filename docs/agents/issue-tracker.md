# Seguimiento de tareas: Markdown local

Los issues y las especificaciones de este repositorio se guardan en `.scratch/`.

## Convenciones

- Un directorio por funcionalidad: `.scratch/<nombre-de-funcionalidad>/`
- La especificación se guarda en `.scratch/<nombre-de-funcionalidad>/spec.md`
- Cada issue de implementación se guarda en un archivo separado dentro de `.scratch/<nombre-de-funcionalidad>/issues/`, numerado desde `01`
- No inventar etiquetas de triage: este repositorio no tiene un vocabulario de triage configurado
- Agregar comentarios e historial de conversación bajo el encabezado `## Comentarios`

## Publicar y consultar

Cuando una skill indique publicar en el issue tracker, crear el archivo Markdown correspondiente dentro de `.scratch/<nombre-de-funcionalidad>/`.

Cuando una skill indique consultar un issue, leer el archivo referenciado.
