# Documentación del dominio

Este repositorio tiene un único contexto de dominio.

Antes de explorar un área, consultar el `GLOSSARY.md` de la raíz y las decisiones pertinentes de `docs/adr/`, si existen. Si no existen, continuar sin crearlos de antemano; crearlos solo cuando se resuelva un término de dominio o una decisión.

Usar los términos establecidos en el glosario en las especificaciones y conversaciones técnicas. Si una propuesta contradice una decisión existente, señalarlo en lugar de reemplazarla silenciosamente.
