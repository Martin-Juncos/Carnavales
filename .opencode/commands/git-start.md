---
description: Crea una rama de tarea desde developer
---

Carga la skill `git-workflow` y ejecuta «Iniciar una tarea».

Nombre de la rama solicitado: $ARGUMENTS

Acepta un nombre como `feat/selector-de-evento` o `fix/guardar-voto`.
Si recibes solo `selector-de-evento`, usa `feat/selector-de-evento`.
Si falta el nombre, muestra cómo invocar el comando.

Crea la rama desde `origin/developer` actualizado y muestra la rama activa.
Si hay cambios locales pendientes, informa cuáles son y detente antes de
cambiar de rama. La rama se crea localmente.
