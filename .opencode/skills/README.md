# Skills del proyecto

Skills locales de OpenCode en español, seleccionadas para el stack actual y las
reglas de Carnavales 2027:

- [`desarrollo-dirigido-por-pruebas`](desarrollo-dirigido-por-pruebas/SKILL.md):
  ciclo de pruebas ajustado a `node:test`.
- [`verificar-antes-de-finalizar`](verificar-antes-de-finalizar/SKILL.md):
  exige evidencia antes de declarar una tarea completa.
- [`practicas-react-vite`](practicas-react-vite/SKILL.md): principios React
  adaptados al cliente actual, sin asumir Next.js ni dependencias ausentes.
- [`seguridad-api-carnavales`](seguridad-api-carnavales/SKILL.md): controles
  derivados de `AGENTS.md` y de la documentación de autenticación.
- [`postgres`](postgres/SKILL.md): diseño de esquemas, exploración de solo
  lectura y migraciones seguras para el PostgreSQL directo del proyecto.

Las skills externas fueron adaptadas y traducidas, no copiadas íntegramente. Las
fuentes y licencias se indican en cada archivo. No se agregaron skills de
Playwright ni guías atadas a ORM/frameworks que el proyecto no utiliza.
